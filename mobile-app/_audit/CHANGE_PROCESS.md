# TendAI UI Change Process (single, repeatable)

1) Назвать проблему (1 строка)
2) Указать Owner (feature, который отвечает)
3) Указать контракт (какой файл из UI_CONTRACTS.md затрагиваем)
4) Изменения только в одном месте (один CSS-блок / один feature)
5) Проверка по чеклисту (до/после) из UI_REGRESSION_CHECKLIST.md

Никаких правок без указания owner и контракта. Любая правка фиксируется этим порядком.
